# RPG Игра на Python (ООП)

Практическая работа №2 — Синтаксис языка Python. Парадигма ООП и проектирование классов.

## Описание

Консольная RPG-игра на Python, реализующая объектно-ориентированное программирование. В игре есть юниты разных типов, игровое поле с ландшафтом, база для создания войск, нейтральные объекты и счётчик экземпляров с сохранением в JSON.

## Требования

- Python 3.10 или выше
- Библиотека colorama (устанавливается командой `pip install colorama`)

## Запуск

1. Установить зависимости: pip install colorama
2. Запустить игру: python main.py

## Управление

В главном меню доступны следующие пункты:

- **1** — Управление базой (создание юнитов, просмотр состояния)
- **2** — Управление юнитом (перемещение, использование способностей)
- **3** — Загрузить игру из файла
- **4** — Сохранить игру в файл
- **5** — Закончить ход (показать поле)
- **6** — Начать новую игру
- **0** — Выйти из игры

## Юниты

В игре 6 видов юнитов, разделённых на 3 типа:

- Пехота: Мечник (M), Копейщик (S)
- Лучники: Лучник (A), Арбалетчик (B)
- Маги: Маг (G), Целитель (H)

## Ландшафт

На поле встречаются 4 типа ландшафта:

- Трава (.) — обычный проход
- Лес (♣) — замедляет движение
- Горы (^) — труднопроходимы
- Вода (~) — непроходима

## Нейтральные объекты

На поле случайно появляются объекты, с которыми могут взаимодействовать юниты:

- Сундук (C) — даёт золото
- Фонтан (F) — восстанавливает здоровье
- Ловушка (T) — наносит урон
- Торговец ($) — продаёт улучшения

## Вариант выполнения

Вариант 17. Задача 4: реализован класс, подсчитывающий количество своих экземпляров в приложении. Перегружен метод `__del__` для корректного отображения числа. Класс и информация о нём сохраняются на диск в виде JSON-файла, также реализован метод загрузки данных из файла.
